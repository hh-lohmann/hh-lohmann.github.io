# Frontend hh.lohmann

Dies ist eine GitHub-Pages-Website, also basierend auf Jekyll, der Urmutter aller Static-Site-Generatoren (und historisch ein enger Verwandter von GitHub).

**Static-Site-Generatoren erzeugen statische Builds, keine statischen Runtimes** (muss es immer noch erklärt werden?). Der Browser erhält fertige Seiten, mit denen interagiert werden kann. Sehr schnell, solange eine stabile Internet-Verbindung besteht.

Einige Unterseiten hier enthalten möglicherweise **Web-Apps, in denen Build- und Runtime nicht getrennt sind**. Der Browser erhält also zunächst Code, mit dem er eine Seite erzeugen muss, mit der dann interagiert werden kann. Sehr praktisch, wenn keine durchgehend stabile Internet-Verbindung besteht (insofern es tatsächliche Web-Apps sind und nicht unreflektierte umständliche Nachahmungen statischer Seiten).

Spannend wird es, wenn tatsächlich (möglicherweise sensible) **Daten mit erforderlicher Authentifizierung und Autorisierung dynamisch bezogen, geändert und persistiert** werden müssen.
